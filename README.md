# 🐾 Patinhas Felizes Pet Store

Pet Store Patinhas Felizes utilizando a plataforma Lovable, aplicação web desenvolvida para o curso Be Digital Power Developer, low-code, com foco na apresentação de produtos e serviços para pets por meio de uma interface moderna e responsiva.

## 🚀 Deploy

Acesse a aplicação:

https://patinhas-felizes-pet-store.lovable.app/

## 📋 Sobre o Projeto

O projeto foi desenvolvido utilizando a plataforma Lovable e tem como objetivo disponibilizar uma experiência digital para uma pet shop através de uma interface web intuitiva e responsiva.

## 🛠️ Tecnologias Utilizadas

### Front-end

* React 19
* TypeScript
* Vite
* TanStack Start
* TanStack Router
* TanStack React Query

### Estilização

* Tailwind CSS 4
* Tailwind Merge
* tw-animate-css

### Componentes e Interface

* Radix UI
* Lucide React
* Embla Carousel
* Sonner

### Formulários e Validação

* React Hook Form
* Zod
* Hookform Resolvers

### Backend e Serviços

* Supabase
* Lovable Cloud Auth

### Qualidade de Código

* ESLint
* Prettier

## 🤖 Desenvolvimento com IA

Este projeto foi desenvolvido utilizando a plataforma Lovable, empregando engenharia de prompts para criação e evolução da aplicação.

## ▶️ Executando o Projeto

### Instalar dependências

```bash
npm install
```

### Executar em ambiente de desenvolvimento

```bash
npm run dev
```

### Gerar build de produção

```bash
npm run build
```

### Visualizar build localmente

```bash
npm run preview
```
